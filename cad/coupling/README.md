# GyroRoll R1B · 中央车钩连接件

[打开交互模型](index.html) · [单机收纳 STEP](GyroRoll_R1B_connection_single.step) · [四机直行总装 STEP](GyroRoll_R1B_connection_four.step)

以 [R1B 齐平机身](../body-print.md) 为基准。连接前取下机身两侧的连接口遮盖。四台机器同向。同排主轮中心相距 340 mm，直行时前后排中点相距 450 mm。

| 部位 | 模型与装配方式 |
|---|---|
| 机身接口 | 每侧以 2 颗 M5 固定在金属叉臂上。两孔沿前后方向相距 58 mm，孔中心离地 297.5 mm。模型已在两侧叉臂加 Ø5.5 安装孔。 |
| 左右半横梁 | 24 × 24 × 2 mm 方管，中心离地 339.5 mm。左端矩形连接舌插入邻机右侧承力座，使用 Ø6 直销。 |
| 右侧纵杆 | 每台各带前、后两根纵杆。前端为插舌，后端为双耳叉，各有独立导套。三段杆件沿导套同轴伸缩，收纳时仍占用承力座前后空间。 |
| 中央铰轴 H | 1 号后杆和 3 号前杆接合，使用 Ø8 竖直销。直行时 H 距每排中点 225 mm。2、4 号两根纵杆收回。 |
| 货架前支点 | 前排横梁中点的竖直转盘连接同一块刚性货架。 |
| 货架后支点 | 后排转盘上方装滑块，沿货架的前后方向滑动。两排相对折转 36° 时，前后排中点间距约 428.0 mm，滑块前移约 22.0 mm。 |

先连接同排的左右半横梁并插销，再伸出 1 号后杆、3 号前杆，在 H 处装竖直销。两排中点上方最后安装货架支承。拆装被立柱覆盖的横梁插销时，需先让出立柱。

HTML 可切换单机和四机、隐藏货架、拖动折转滑条。角度按前、后排的角度差计算。STEP 四机总装保存直行姿态。以刚体几何检查了 0°、±18°、±36° 五个装配姿态，体积大于 0.15 mm³ 的重叠见 [检查结果](clearance.json)。该模型用于接口和运动复核。伸缩杆级间锁止、连接强度、销轴防脱和整机倾斜时的动态间隙仍需工程设计。

使用与上级 R1B 相同的 Python 和 OCP 环境，在项目根目录运行 `python src/coupling/build_connections.py` 可重建。
